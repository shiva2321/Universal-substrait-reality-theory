   diamond with N =  100 expected elements: links from the bottom element 5.199 +- 0.030; exact Ein(N) = ln N + gamma_E + E1(N) = 5.182

   sprinkling can pick a direction; discreteness and exact Lorentz symmetry coexist.

D. Waves on a causal set: Sorkin's d'Alembertian is exactly Lorentz invariant on average
==============================================================================
   B phi(x) = (4/l^2)[ -phi(x)/2 + sum_L1 phi - 2 sum_L2 phi + sum_L3 phi ], L_n = past elements with n-1
   elements between them and x (Sorkin, gr-qc/0703099).  Mean over sprinklings, plane wave e^{i(k_u a + k_v b)}
   (a, b = past null distances): the b-integral is exact, (c-beta)^2/c^3 = -k_v^2/(beta - i k_v)^3, giving
   E[B]/phi = 4 rho (I(zeta) - 1/2),  I(zeta) = -int_0^inf e^{i zeta s}/(s - i)^3 ds,  zeta = 2 k_u k_v / rho
   exact (sympy): I(0) = 1/2, I'(0) = 1/2  ->  E[B]/phi = 4 k_u k_v + ... = (omega^2 - k^2) + ...
   so E[B phi] -> -box phi in the continuum (our signature +,-), with corrections that depend only on
   zeta ~ k^2 l^2. A boost multiplies k_u by lambda and divides k_v by lambda: zeta is unchanged. EXACT.
   example k_u k_v = 0.0625: exact mean 0.287870+0.086639i
   boost lambda = 1.0: brute-force quadrature in a fixed truncated region A = 12, 24, 48: 0.28576+0.08409i, 0.28817+0.08704i, 0.28792+0.08669i  -> same limit
   boost lambda = 2.0: brute-force quadrature in a fixed truncated region A = 12, 24, 48: 0.28136+0.09346i, 0.28684+0.08539i, 0.28803+0.08684i  -> same limit
   boost lambda = 4.0: brute-force quadrature in a fixed truncated region A = 12, 24, 48: 0.28858+0.13286i, 0.28121+0.09326i, 0.28682+0.08536i  -> same limit
   Monte Carlo sprinklings (rho = 1), 600,000 each, in the diamond A = 12 seen from two frames
   (wave AND region boosted together: a' = a/lambda, b' = b lambda):
   frame lambda = 1.0: MC 0.2914+-0.0142 +0.0626+-0.0202i  (exact for this region 0.285765+0.084086i; deviation 0.4 and 1.1 sigma); spread of ONE sprinkling 11.0
   frame lambda = 2.0: MC 0.2822+-0.0142 +0.0579+-0.0202i  (exact for this region 0.285765+0.084086i; deviation 0.3 and 1.3 sigma); spread of ONE sprinkling 11.0
   the exact region values in the two frames are identical: |difference| = 0.0e+00
   chi^2 of the 4 Monte Carlo numbers against the exact value: 3.0 for 4 degrees of freedom
   lattice d'Alembertian (spacing = l) on the same three boosted waves: 0.24483, 0.23909, 0.21023  (continuum 4 k_u k_v = 0.25000): it depends on the frame
   zeros off the light cone: min |E[B]| / min(2|zeta|, 2) = 0.415 over 1e-3 <= |zeta| <= 30, both time
   orientations (the mean grows like 2 zeta near the cone and tends to -2 far from it; it never vanishes)
=> on average, waves on a causal set obey a dispersion relation that is a function of k^2 alone, vanishing
   only on the light cone: massless waves travel at EXACTLY c at every energy, in every direction. No
   3:1 TeV delay pattern (r10), no species-dependent speeds, so the r13 graviton-speed problem does not
   arise (r13 showed a Lorentz-invariant regulator gives c_g = c exactly).
   PRICE: a single sprinkling is very noisy (spread 11 vs signal ~0.3): the operator is NON-LOCAL
   (elements far along the light cone contribute). Physical fields need a non-locality scale l_k >> l
   (Sorkin 2007) -- a new, testable length.

F. The cosmological constant as a counting fluctuation (Sorkin)
==============================================================================
   4-volume of the observable universe ~ (c/H0)^4 = 5.2e+243 Planck units; if the number of elements
   fluctuates by sqrt(N), Lambda ~ 1/sqrt(N) = 1.4e-122 (Planck units)
   observed Lambda l_P^2 = 2.8e-122  -- same order of magnitude
   (argued by Sorkin before 1998's discovery of cosmic acceleration; 'everpresent Lambda': Ahmed,
   Dodelson, Greene & Sorkin, PRD 69, 103523 (2004)). Order of magnitude only; O(1) factors open.
