   The effective potential is Phi = (c(x)^2 - c^2)/2, i.e. gravity = a map of the local wave speed.

==============================================================================
D. 3D: the full light bending requires eps = mu (impedance matching)
==============================================================================
eps = mu = K = 1 + 2GM/rc^2 -> n = K:        deflection 1.7512 arcsec (GR: 1.7512; VLBI confirms GR to ~1e-4)
eps = K, mu = 1           -> n = sqrt(K):  deflection 0.8756 arcsec (half: excluded)
local impedance Z = Z0 sqrt(mu/eps): unchanged if eps = mu, so local physics (alpha = e^2 Z0/2h) is
identical everywhere -- that IS the equivalence principle for electromagnetically bound matter.
if eps != mu: alpha would track the Sun's potential at Earth, which changes by 3.3e-10 over the year;
  atomic-clock comparisons bound that coupling at the ~1e-6 level or below (e.g. Leefer et al. 2013),
  so a mismatched response (coupling ~1) is excluded by about a million.
=> requirement on the substrate: trapped energy must change its electric and magnetic stiffness
   equally. Conjecture: this is automatic if the loop condensate is symmetric between electric and
   magnetic loops (electric-magnetic duality). In GR the same fact is Plebanski's (1960) result that
   gravity acts on light like a medium with eps_ij = mu_ij.
