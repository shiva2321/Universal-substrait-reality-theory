A. r23-B: is the Calugareanu-White-Fuller check in r23 a test?
==============================================================================
r23 computes Wr, then SETS Tw = Lk_exact - Wr and prints Lk = Wr + Tw. That returns Lk_exact for ANY Wr.
   r23 pipeline, converged Wr (A = 0.48)       : Tw =    +2.1651, Lk = Wr + Tw = 1.0000000000000000   |Lk - 1| = 0.0e+00
   r23 pipeline, deliberately wrong Wr = +0.70 : Tw =    +0.3000, Lk = Wr + Tw = 1.0000000000000000   |Lk - 1| = 0.0e+00

B. r23-D: does equipartition give g = 2 and spin hbar/2?
==============================================================================
   mu = q c R / 2 ;  J = f M c R ;  J = hbar/2  =>  R = hbar/(2*M*c*f) ;  g = mu / [(q/2M) J] = 1/f  (sympy)
   So g = 1/f: the 'derivation' is the choice f = 1/2 (half the energy circulating, half 'poloidal').
   f = 1   -> g = 1 (bare loop);   f = 1/2 -> g = 2 exactly;   measured g_e = 2.00231930436 needs f = 0.499421 (0.116 % below 1/2).
   Equipartition is assumed, not derived; with it g = 2 comes out because 1/f = 2 was put in.
   Quadrature over a torus (R = 1.0, minor radius 0.3): L_z(poloidal flow) / L_z(toroidal flow, same speed) = +5.9e-20
   A poloidal (around-the-tube) flow lies in the meridional plane, so rho*v_phi = 0 and it adds NOTHING to J_z.
   r23 counts it as a second hbar/2. Its own formula S_pol = (E_pol/c^2) r0 c equals hbar/2 only if the tube
   radius r0 equals the major radius R = hbar/(Mc); for a thin torus S_pol = (hbar/2)(r0/R):
      r0/R = 1.0:  S_pol = 0.50 hbar
      r0/R = 0.3:  S_pol = 0.15 hbar
      r0/R = 0.1:  S_pol = 0.05 hbar
   Schwinger term: 2(1 + alpha/2pi) = 2.0023228195; residual to the measured g_e = +3.515e-06. This is
   textbook QED (1948). r23 attributes it to 'substrate gauge fluctuations (computed in r02)'; r02 contains no
   g-2 calculation (searched: no 'schwinger', 'anomal' or 'g-2' in r01-r22). '99.85 % explained' is QED's credit.
   Constants: the number typed into r23 as 'CODATA 2022' (2.00231930436256) is the CODATA 2018 value; CODATA 2022 is
   2.00231930436092(36) (from memory: a_e = 1.15965218046(18)e-3 gives exactly that; not re-fetched). Effect: 1.6e-12.
   Verdict B: the numbers g = 1 (bare loop) and the Schwinger arithmetic are right; 'g = 2 identically from
   geometry' is NOT derived (g = 1/f with f = 1/2 assumed), the spin accounting double-counts, and Schwinger is QED's.

   regularized causal path sum ... uniquely selects d = 3+1' is not a result of the simulation.
