B. Strong gravity: GR vs a multiplicative ('exponential') substrate response
==============================================================================
  Schwarzschild (GR)   isotropic coords: PPN gamma = 1, beta = 1  -> solar-system tests identical
  exponential          isotropic coords: PPN gamma = 1, beta = 1  -> solar-system tests identical
  photon-capture impact parameter (shadow radius), units GM/c^2: GR 5.1962 (= 3 sqrt3), exponential 5.4366 (= 2e)
  => shadow +4.63% larger than GR for the same mass and distance
  Event Horizon Telescope, Sgr A* (2022): fractional deviation delta = -0.08 +- 0.09 (VLTI mass) and
  -0.04 +0.09/-0.10 (Keck mass): the exponential value +0.046 is 1.4 and 1.0 sigma away
  -> allowed today; ngEHT / space VLBI aim for a few percent.
  Horizon: GR has one at r = 2GM/c^2; the exponential metric has none (g_tt = -e^{-2GM/rc^2} never
  vanishes) and a throat of areal radius e*GM/c^2 instead: a horizonless object, which predicts
  ringdown 'echoes'. LIGO-Virgo-KAGRA ringdowns agree with GR black holes so far; echoes are not
  robustly seen. This makes the multiplicative completion testable and under pressure.
  light bending = 4 (GM/bc^2) + C2 (GM/bc^2)^2: C2(GR) = 11.7809
  light bending = 4 (GM/bc^2) + C2 (GM/bc^2)^2: C2(exponential) = 12.5663
  analytic: GR 15 pi/4 = 11.7810; exponential 4 pi = 12.5664
  at the Sun's edge the 2nd-order difference is 0.73 micro-arcseconds: below current reach (future sub-uas astrometry).
