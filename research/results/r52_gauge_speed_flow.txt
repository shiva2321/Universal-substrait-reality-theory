L1. Fermion self-energy in Coulomb gauge: three checks
==============================================================================
Self-energy (v = 1): Sigma(k) = s e^2 Int d^4q/(2 pi)^4 [ gamma0 G(k+q) gamma0 / (eps q^2) + sigma gamma_j G(k+q) gamma_i (delta_ji - qhat_j qhat_i) / (eps (q0^2 + c_g^2 q^2)) ],
G(p) = -i (gamma0 p0 + gamma.p) / (p0^2 + p^2).  Dirac algebra: gamma0 (gamma0 p0 - ... ) gives gamma0 p0 - gamma.p for the Coulomb term and -2 gamma0 p0 - 2 (qhat.gamma)(qhat.p) for the transverse term;
after expanding to first order in k and averaging over the direction of q, the 4D angle integrals are (sin^2 chi is the measure):
    I0 = Int_0^pi [ (sin^2 - cos^2) (1 - 2 sigma sin^2 / P) ] dchi,        P = cos^2 chi + x^2 sin^2 chi          (coefficient of gamma0 k0)
    I1 = Int_0^pi [ (-1 + (2/3) sin^2) - (2 sigma / 3) sin^2 (1 - 2 sin^2) / P ] dchi                              (coefficient of gamma.k)
    d ln v / dL = - alpha_v (I1 - I0) / pi^2   (the overall sign s = -1 is fixed by the Coulomb limit below; the relative sign sigma by Lorentz invariance).

    (a) Lorentz invariance, x = 1:  sigma = +1: d ln v / dL = -4.500e-17 alpha_v   (zero);   sigma = -1: +0.4244 alpha_v   (the wrong sign does not cancel: the check discriminates).
    (b) Coulomb limit, x -> infinity: x = 1e4: 0.21220659 alpha_v;   2/(3 pi) = 0.21220659.  Relative difference 1.1e-13 (the transverse photon decouples: the closed form below deviates from 2/(3 pi) as 4/x^3).

L2. Photon side: vacuum polarisation of a fermion of speed v
==============================================================================
Dirac fermion loop: delta eps / eps = n (2 alpha_v / 3 pi) dL (Uehling, with the fermion speed v in alpha_v = e^2 / (4 pi eps v)); the magnetic part follows from the Lorentz invariance of the fermion sector
(speed v): delta(1/mu) = v^2 delta eps.  Hence  d ln c_g^2 / dL = [delta(1/mu)/(1/mu) - delta eps / eps] / dL = (n 2 alpha_v / 3 pi) (v^2 / c_g^2 - 1):
    d ln c_g / dL = - n (alpha_v / 3 pi) (1 - 1/x^2).
Inputs (typed in, not computed here): the Uehling coefficient 2 alpha / (3 pi) per Dirac fermion and the structure delta(1/mu) = v^2 delta eps.
Check: x = 1 gives no flow of c_g (Lorentz invariance); x >> 1 gives the rate alpha_v / (3 pi) quoted in E48; the charge: d alpha_v / dL = alpha_v (- d ln eps / dL - d ln v / dL) = -(2 n alpha_v^2 / 3 pi) at x = 1,
i.e. the standard QED beta function dalpha/dln(mu) = + 2 n alpha^2 / (3 pi) per Dirac fermion (n = 1 is the textbook value 2 alpha^2 / 3 pi).
    numbers for alpha = 1/137: d ln c_g / dL = -7.743e-04 (x -> inf), d ln v / dL = 1.549e-03, d ln eps / dL = 1.549e-03 per e-fold.

==============================================================================
L3. The coupled flow and the approach to one light cone
==============================================================================
    d ln x / dL = -(alpha_v / 3 pi) [ n (1 - 1/x^2) + 2 (1 - 4 / (x (1 + x)^2)) ],    d ln alpha_v / dL = -(2 n / 3 pi) alpha_v - alpha_v g(x).
    Near x = 1 (delta = x - 1):  d delta / dL = -(2 (n + 2) alpha_v / 3 pi) delta   and   d alpha_v / dL = -(2 n / 3 pi) alpha_v^2,  so  delta ~ alpha_v^(1 + 2/n) ~ (1 + 2 n alpha_0 L / 3 pi)^(-(1 + 2/n)):
    the approach to one light cone is a POWER LAW IN L = ln(scale), not exponential in L, because the coupling itself runs to zero (marginally irrelevant) at the same time.
      n (Dirac fermions)    rate (2(n+2)/(3 pi)) alpha / e-fold   exponent 1 + 2/n
                     0.5                                 0.5305               5.00
                     1.0                                 0.6366               3.00
                     2.0                                 0.8488               2.00
                     8.0                                 2.1221               1.25
    (n = 1/2 is one Weyl node; n = 8 is the sum of Q^2 N_colour over all charged Standard-Model fermions above their masses, if they all had the same speed v.)

    Numerical check (n = 1, x0 = 1.05, alpha0 = 0.5, integrated over 400 e-folds): d ln delta / d ln alpha = 3.0000   (predicted 1 + 2/n = 3).
