==============================================================================

Structure of a KR poset: Layer 1 (N/4), Layer 2 (N/2), Layer 3 (N/4).

Exact analytical predictions:
   - Links N1_KR = (N/4)(N/2)(1/2) + (N/2)(N/4)(1/2) = N^2 / 8 = 0.125 N^2   (quadratic explosion!)
   - Relations R_KR = (3/16) N^2 = 0.1875 N^2   =>   ordering fraction r_KR = 3/8 = 0.3750
   - Proper time (height L) = 3 for ALL N (time never advances past 3 discrete ticks!)
