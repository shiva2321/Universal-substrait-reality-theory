4. The '7.2' calibration and the de Boer parameter
==============================================================================
paper: mu0/rho0 = 7.200 V0/M0  -> V0 = M0 c^2 / 7.2
correct Cauchy-Born: mu_V/rho0 = 28.800 V0/M0 -> V0 = M0 c^2 / 28.8
Lambda* = hbar/(a0 sqrt(M0 V0)) with a0 = l_P, M0 = m_P, V0 = M0 c^2/X  equals sqrt(X) EXACTLY,
because hbar = l_P m_P c.   paper X = 7.2 -> Lambda* = 2.6833 (direct: 2.6833)
with the corrected X = 28.8 -> Lambda* = 5.3666
So Lambda* is not an independent result: it is the square root of the fitting constant.
Either way Lambda* > 0.3, i.e. by the paper's own criterion the 'crystal' is a quantum LIQUID;
a liquid has zero static shear modulus, so the Cauchy-Born shear modulus used to make light
does not exist in that state. The two headline claims are mutually exclusive.

5. Can a speed be built from hbar and G alone?
==============================================================================
hbar^x G^y must have units m/s: kg: x - y = 0;  m: 2x + 3y = 1;  s: -x - 2y = -1
kg & m give x = y = 1/5, but s needs x = y = 1/3  -> contradiction, no solution.
(numerical least-squares check: best (x, y) = [0.2        0.25714286], residual [0.11428571] != 0)
=> No combination of hbar and G is a velocity. Planck mass and Planck length both contain c,
   so 'c emerges as sqrt(mu/rho)' only returns the c that was put into M0, a0 and V0.
   A genuine prediction of c would need M0 and a0 measured independently of c.

6. HCP or FCC? (the documents use both interchangeably)
==============================================================================
HCP: the 3 neighbours above and the 3 below sit at the SAME (x,y): True  -> stacking ABAB
FCC: the upper and lower triangles are rotated 60 deg relative to each other -> stacking ABCABC
The preprint's Calc. 1.6 neighbour vectors (a/sqrt2)(+-1,+-1,0)... are FCC, the treatise calls
the lattice HCP, and the '3 generations / 3 colours from A->B->C stacking' argument needs FCC.
