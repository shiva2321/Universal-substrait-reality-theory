1. Electron mass formula  m_e = m_P (sqrt3/2) exp(-[3/(8 alpha) - (alpha/2pi) sqrt12])
==============================================================================
ln(m_P/m_e) = 51.5278400 +- 1.1e-05   (uncertainty set by G: 2.2e-5 relative)
  exp(-3/(8a))                       [found by noticing 51.53 ~ 0.375*137]
     -> m_e = 0.587401 MeV  rel. error +1.495e-01  = 12,400 sigma
  (sqrt3/2) exp(-3/(8a))             [+ prefactor picked to fit]
     -> m_e = 0.508704 MeV  rel. error -4.491e-03  = 401 sigma
  (sqrt3/2) exp(-[3/(8a)-(a/2pi)sqrt12]) [+ term picked to fit]
     -> m_e = 0.510755 MeV  rel. error -4.774e-04  = 42 sigma
The 'action accuracy 99.999%' quoted in the documents divides the error by 51.5; that is not a
measure of agreement. The relevant comparison is the last line: the final formula misses by
4.8e-4 while the measurement (limited by G) is good to 1.1e-5, i.e. it is excluded at ~40 sigma.
Prior art: alpha*ln(m_P/m_e) = 3/8 (the leading term, with 3/8 attributed to GUTs) is L. Nottale's
scale-relativity 'mass-charge relation' (1990s; arXiv:hep-th/0307093, arXiv:2104.03924).
The repository script electron_mass_hierarchy_proof.py records the actual discovery route:
  '# Notice: 51.528 is remarkably close to (3/8) / alpha = 0.375 * 137.036 = 51.388 !'

3. Charged-lepton masses: Koide Q = 2/3 and the phase delta = 2/9
==============================================================================
Koide Q (PDG 2024) = 0.6666645 +- 0.0000051;  2/3 differs by -0.43 sigma
  -> Q = 2/3 is a genuine, still unexplained empirical regularity (Koide 1981/1983). Real, but
     not new, and not derived by USRT: the parametrisation sqrt(m_k) = v0[1 + sqrt2 cos(d + 2pi k/3)]
     gives Q = 2/3 identically for ANY v0 and d, so it cannot 'prove' Q = 2/3.
delta fitted to (m_e, m_mu) with Q = 2/3 built in: 0.222222047   vs 2/9 = 0.222222222
with delta = 2/9 exactly: m_mu = 105.659414 MeV vs measured 105.6583755 +- 0.0000023  -> 452 sigma off
tau from (m_e, m_mu) + Q = 2/3: 1776.969 MeV vs PDG 2024 1776.93 +- 0.09  -> +0.43 sigma (this is Koide's old successful prediction)
Prior art: delta ~ 2/9 was noticed by C. Brannen and G. Rosen (c. 2006); the USRT 'derivation'
(trace normalisation 2 / phase-space dimension 9) is a numerical label, not a calculation.

CODATA 2022       = 1836.152673426 +- 3.2e-08

==============================================================================
Planck 2018: Omega_c h^2 / Omega_b h^2 = 5.3643 +- 0.0646
5 + 3/8 = 5.3750 -> pull +0.17 sigma
5 + sin^2(theta_W) at low energy (0.2312) = 5.2312 -> pull -2.06 sigma
  (so the choice of the GUT-scale 3/8 rather than the measured 0.231 is what makes it 'work')
Simple fractions p/q (q <= 12) inside 1 sigma: 7: 53/10, 16/3, 59/11, 43/8, 27/5, 65/12, 38/7

6. Neutron-proton mass difference
==============================================================================
CODATA 2022 m_n - m_p = 1.29333251 +- 3.8e-07 MeV
USRT: (m_d - m_u) = 2.0500 MeV minus EM = 0.7567 MeV -> 1.2933 MeV. The two inputs are not
derived; 0.7567 is chosen so that the difference reproduces the measured value to 4 decimals.
Actual first-principles result (BMW collaboration, Borsanyi et al., Science 347, 1452 (2015),
lattice QCD+QED): QCD (m_d - m_u) part ~ +2.5 MeV, QED part ~ -1.0 MeV, total 1.51 +- 0.28 MeV.
